# ETN HI-STORM Temperature Data Plotter

This is a simple automation script to plot temperature data from equipment.

## Streamlit

The app is hosted on Streamlit sharing, you can access it by clicking the badge below:

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://etn-hs-temp.streamlit.app/)

## Usage

After getting the data from the equipment, just open the Streamlit app and upload the file.

It will plot the data and show the temperature values, allowing you to download all the plots as PNG files. It also generates the WORD document to be used in the report.
